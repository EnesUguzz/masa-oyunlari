# Okey Botları v1 (güvenli auto-play) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Let a single human play okey against 3 server-driven bots that auto-play with the engine's existing safe `autoMoves` (no LLM, no cost).

**Architecture:** Generic "add bots to room" capability in core + an okey-specific `driveBots` loop that auto-plays bot seats via `OkeySession.autoPlayTurn`. Server authority + per-player privacy unchanged (bots have no socket).

**Tech Stack:** TypeScript (strict, NodeNext), Vitest, Socket.IO, React.

**Spec:** `docs/superpowers/specs/2026-06-16-okey-bots-v1-design.md`

```ts
  addBots(code: RoomCode, count: number): Room | undefined {
    const room = this.repo.get(code);
    if (!room) return undefined;
    const free = room.capacity - room.players.length;
    const toAdd = Math.max(0, Math.min(count, free));
    for (let i = 0; i < toAdd; i++) {
      const n = room.players.filter((p) => p.isBot).length + 1;
      room.players.push({ id: this.botId(), nickname: `Bot ${n}`, isBot: true });
    }
    this.repo.update(room);
    return room;
  }

  private botId(): PlayerId {
    let s = "bot_";
    for (let i = 0; i < 6; i++) s += CODE_ALPHABET[this.rng.nextInt(CODE_ALPHABET.length)]!;
    return s as PlayerId;
  }
```

```ts
  const driveBots = (code: string): void => {
    const session = store.get(code);
    if (!session) return;
    let guard = 0;
    while (!session.isOver && session.isBotSeat(session.currentSeat) && guard++ < 10000) {
      session.autoPlayTurn(session.currentSeat);
    }
  };

  const advance = (code: string): void => {
    driveBots(code);
    const session = store.get(code);
    if (!session) return;
    if (session.isOver) {
      broadcast(code, OkeyServerEvents.ended);
      rooms.setStatus(code, "finished");
      store.end(code);
    } else {
      broadcast(code, OkeyServerEvents.state);
      armTimer(code);
    }
  };
```

```ts
    socket.on(ClientEvents.addBots, (raw: unknown) => {
      try {
        addBotsSchema.parse(raw);

        const room = code ? rooms.getRoom(code) : undefined;
```

## Notes for the implementer
- **No LLM / cost:** bots reuse `OkeySession.autoPlayTurn` (safe `autoMoves`). Pure, local.
- **Privacy unchanged:** bots have no socket; `broadcast` skips them; their hands stay hidden via `toOkeyPlayerView`.
- **Server authority:** `addBots` is owner-only and waiting-only; the engine still validates every move.
- **Out of scope:** smart heuristic bot, inter-move delays, removing/replacing bots.
